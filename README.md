# Story Loom — Branching Dialogue Tree Builder

A branching dialogue tree builder for narrative and game writers. Pin dialogue nodes to a corkboard, thread choices between them, and playtest the conversation live — built to match how writers actually think about branching dialogue, not just as a form.

## Features

- **Board view** — author dialogue nodes with speaker, text, and branching choices
- **Play view** — click through your dialogue tree live, exactly as a player would
- Autosaves as you write
- Comes seeded with an example conversation

## Tech Stack

- Next.js 14 (App Router)
- React
- Tailwind CSS
- Node.js / API routes

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Why I built this

I wanted a tool that matched how I think about dialogue when writing for games — branching nodes with choices, not text in a spreadsheet. Story Loom lets me author a conversation and immediately playtest whether the pacing and branching actually land.
